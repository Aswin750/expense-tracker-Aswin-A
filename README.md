# Expense Tracker

A simple expense tracker built using HTML, CSS and JavaScript.

## Features

- Add income and expenses
- Edit transactions
- Delete transactions
- Calculate total income
- Calculate total expenses
- Calculate current balance
- Filter by type
- Filter by category
- Monthly summary
- Category-wise expense chart
